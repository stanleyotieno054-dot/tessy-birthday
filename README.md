# 🎂 Happy Birthday, Tessy! ❤️

A beautiful, romantic, and interactive birthday surprise website made with love.

## 🎁 Features

✨ **Secret Code Protection** - Enter code `2008` to unlock the surprise

💕 **Romantic Birthday Message** - A heartfelt personalized message

🎵 **Music Player** - Add a special song to make it even more magical

📸 **Photo Gallery** - Display beautiful memories and moments together

🎉 **Birthday Wishes** - Heartfelt wishes to celebrate the special day

💖 **Falling Hearts Animation** - Romantic falling hearts throughout the page

📱 **Mobile-Friendly** - Perfect on any device (especially phones)

🎨 **Smooth Animations** - Beautiful transitions and interactive effects

## 🚀 How to Use

1. **Visit the Website**: Open `index.html` in your browser or access via GitHub Pages

2. **Enter the Code**: The secret code is `2008` (feel free to change it in `script.js`)

3. **Unlock the Surprise**: Click "Unlock" to reveal the birthday experience

4. **Enjoy**: Scroll through the beautiful message, wishes, and photo gallery

## 🎼 Adding Music

To add a birthday song:

1. Place your audio file (MP3, WAV, etc.) in the project folder
2. Open `index.html`
3. Find the line: `<audio id="birthdayAudio" src="" style="display: none;"></audio>`
4. Add your file path: `<audio id="birthdayAudio" src="your-song.mp3" style="display: none;"></audio>`

## 📸 Adding Photos

To add photos to the gallery:

1. Replace the placeholder `<div>` elements in `index.html` with `<img>` tags
2. Example:
   ```html
   <img src="path/to/your/photo.jpg" alt="Memory 1" class="photo-image">
   ```

## 🌐 Deploying to GitHub Pages

1. Go to your repository settings
2. Scroll to "GitHub Pages"
3. Select "main" branch as source
4. Click Save
5. Your site will be live at: `https://stanleyotieno054-dot.github.io/tessy-birthday/`

## 🎨 Customization

### Change the Secret Code
- Open `script.js`
- Find: `const CORRECT_CODE = "2008";`
- Change `"2008"` to your desired code

### Change Colors
- Open `styles.css`
- Modify the `:root` color variables at the top

### Edit the Birthday Message
- Open `index.html`
- Find the `.birthday-message` section
- Edit the text as desired
